# Ing-Service SC — Web V4

Sitio corporativo estático de Ing-Service SC, preparado para publicarse sin hosting de pago.

## Incluye
- Home corporativa responsive para celular, tablet y escritorio.
- Servicios individuales y proyectos documentados.
- Sección especial de electromovilidad.
- Sección comercial para constructoras, industrias, comercios e inmobiliarias.
- Proceso de cotización y formulario conectado directamente a WhatsApp.
- CTA flotante de WhatsApp.
- SEO básico, Open Graph, Twitter Card, Schema.org, robots.txt y sitemap.xml.
- Página 404 y página informativa de privacidad.
- Web manifest y favicon.
- Sin base de datos y sin servidor: el sitio puede funcionar como web estática.

## Publicación gratuita recomendada
La versión V4 está preparada para publicarse como sitio estático en un servicio con plan gratuito. El dominio propio es opcional; primero puede utilizarse una dirección gratuita y posteriormente conectar un dominio.

## Antes de publicar
1. Confirmar el dominio definitivo. Si no existe dominio propio, mantener la configuración de publicación gratuita.
2. Cuando el dominio real esté definido, reemplazar `https://www.ingservicesc.com/` en canonical, Open Graph, Twitter Card, Schema.org, robots.txt y sitemap.xml.
3. Añadir el enlace real de Facebook/Instagram si se desea incluirlo en Schema.org.
4. Confirmar dirección física y horario antes de añadirlos al Schema.org.
5. Publicar por HTTPS.
6. Después de publicar, registrar el sitio en Google Search Console y enviar `sitemap.xml`.

## Nota
No se inventaron dirección física, horarios, perfiles sociales ni credenciales. Esos datos deben añadirse únicamente cuando Ing-Service SC los confirme.


## Estadísticas de visitas
La web está preparada para Google Analytics 4. Antes de publicar, crea una propiedad gratuita en Google Analytics y obtén el ID de medición (formato `G-XXXXXXXXXX`). Luego se reemplaza el marcador en `index.html` y se habilita el bloque de Analytics. No hace falta pagar por Google Analytics.

Después de publicar también podemos conectar Google Search Console para revisar búsquedas, clics e indexación.
