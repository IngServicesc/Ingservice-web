Privacidad y uso del formulario

Este sitio utiliza un formulario de cotización que prepara un mensaje para enviarlo por WhatsApp. Los datos escritos en el formulario no se almacenan en una base de datos propia de este sitio.

Qué información puedes proporcionar

Nombre o empresa, número de WhatsApp, ubicación, servicio solicitado y una descripción del trabajo. Evita enviar contraseñas, datos bancarios o información que no sea necesaria para la cotización.
